# Facebook Login & Signup Page Clone

## About The Project

This project is a Facebook login and signup page clone created using HTML and CSS.

The purpose of this assignment was to practice real-world authentication UI design, multi-page website structure, form handling layouts, responsive design techniques, and building interconnected pages using proper navigation between login and signup screens inspired by Facebook’s interface.

## Technologies Used

- HTML5  
- CSS3  

## Features

- Facebook-style login page layout with two-column design  
- Left section with logo and description text  
- Right section login form with email and password fields  
- Forgot password link with hover effect  
- Create new account button linking to signup page  
- Fully functional multi-page structure (Login → Signup → Login navigation)  
- Signup page with structured form (name, DOB, gender, password fields)  
- Date of birth dropdown system (day, month, year)  
- Gender selection using radio-style inputs  
- Clean form validation-friendly layout  
- Responsive design for mobile, tablet, and desktop  
- Hover effects and interactive UI states  
- Card-based form design with shadows and spacing  

## What I Learned

Through this assignment, I learned:

- How to build multi-page websites using HTML linking  
- How to structure authentication pages like real applications  
- How to design complex forms (login + signup)  
- How to manage responsive layouts using media queries  
- How to align elements using Flexbox effectively  
- How to improve UI consistency across multiple pages  
- How large platforms structure authentication flows
